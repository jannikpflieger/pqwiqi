Wie können wir etwas extrem Kleines messen, zum Beispiel ein winziges Magnetfeld oder eine sehr geringe Änderung der Gravitation? Klassische Sensoren erfassen eine physikalische Größe normalerweise direkt, etwa indem sie eine Spannung, eine Verschiebung oder eine Intensität messen. Ihre Genauigkeit wird jedoch durch Rauschen und dadurch begrenzt, wie kleine Signale sie noch auflösen können.

Quantensensoren verfolgen einen anderen Ansatz. Anstatt eine physikalische Größe direkt zu messen, verwenden sie ein Quantensystem – beispielsweise ein Atom, ein Photon oder einen Elektronenspin – als Sonde. Das System wird zunächst in einen genau definierten Zustand gebracht. Anschließend lässt man es mit seiner Umgebung wechselwirken, wobei die zu untersuchende physikalische Größe seine Entwicklung leicht verändert. Schließlich wird das System gemessen, und aus dieser Veränderung lassen sich Informationen über die gesuchte Größe gewinnen.

Ein entscheidender Unterschied besteht darin, dass die Information häufig in einer Phase gespeichert wird, die sich im Laufe der Zeit aufbaut. Dadurch können Quantensensoren extrem kleine Effekte mit sehr hoher Präzision nachweisen, teilweise sogar jenseits klassischer Grenzen.

Verschiedene physikalische Plattformen können als Quantensensoren verwendet werden. Atomare Systeme, wie Atomuhren und Atominterferometer, werden häufig für hochpräzise Messungen von Zeit und Gravitation eingesetzt. Festkörpersysteme, darunter Spins in Diamant, die als Stickstoff-Fehlstellen-Zentren oder Nitrogen-Vacancy-(NV)-Zentren bekannt sind, ermöglichen Messungen auf sehr kleinen räumlichen Skalen. Supraleitende Bauelemente wie SQUIDs gehören zu den empfindlichsten Magnetometern, während optische Systeme, die Quantenlicht verwenden, die Messgenauigkeit zusätzlich verbessern können.
