---
title: "Superposition"
subtitle: "A quantum state made from several possible states"
author: "Melin Kayapınar"
date: "2026-08-14"
letter: "S"
---

Superposition describes the fact that any quantum mechanical state of a system can be described as a combination of several other states.

When subjected to a measurement, the system reverts to one of these states. The specific form of the superposition defines the probabilities of obtaining each individual state in a measurement.

For example, it is not possible to assign a specific location to a particle. Instead, it is only possible to define an area with a certain probability density.
